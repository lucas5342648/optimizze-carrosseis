# optimizze-carrosseis

Carrosséis de TikTok da Optimizze AI, gerados automaticamente e agendados pelo Zernio.

- `motor/render.py`: gera os slides (1080x1920) a partir de um `spec.json`.
- `carrosseis/<lote>_<nome>/`: slides numerados (`*_01.jpg`...), `spec.json` e `legenda.txt`.

As imagens ficam públicas porque o Zernio baixa os slides por link na hora de publicar.
